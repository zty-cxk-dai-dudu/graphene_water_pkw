# Archived v23 code and source data

`Graphene_Water_Code_Data_v23.zip` is an unmodified archive from zty (`JACS_code_data_20260914_v23/delivery/`). Its SHA-256 digest is in `SHA256SUMS.txt`.

This archive predates the latest manuscript window harmonization. It must not be interpreted as a recalculation using 600–1000 ps for all conditions. See the repository README for the known window mismatch.
